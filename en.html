HADI Telegram Monitoring

Manage and monitor Docker containers via Telegram bot

🚀 Docker 🤖 Telegram Bot 📊 Real-time

🔍 Overview

This tool allows you to manage your Docker containers remotely using a Telegram bot. View logs, restart containers, and receive reports with just a few taps in Telegram.

✨ Features

📋

Get Logs

Select a container and receive its latest logs as a file.

🔄

Restart

Restart any container with a simple command.

📱

Telegram Access

Do everything from your phone without SSH or terminal.

⚡

Fast Response

The bot continuously listens for your requests.

🤖 Create a Telegram Bot

1

Open Telegram and message @BotFather.

2

Send the command /newbot.

3

Choose a name for your bot (e.g., HADI Monitor).

4

Choose a username ending with bot (e.g., hadi_monitor_bot).

5

After confirmation, copy the token (e.g., 123456:ABC-DEF...). This is your BOT_TOKEN.

💡

Store your bot token securely. Never share it with anyone.

🆔 Get CHAT_ID

1

Start your bot in Telegram (press Start or send /start).

2

To get your numeric chat ID, use one of these methods:

3

Method 1: Use the bot @userinfobot. Start it and send /start. It will show your ID.

4

Method 2 (API): After sending a message to your bot, open this URL in your browser:
https://api.telegram.org/bot<TOKEN>/getUpdates
(Replace <TOKEN> with your bot token.)

5

In the JSON output, look for "chat":{"id":123456789}. The number inside id is your CHAT_ID.

⚠️

If using a group, add the bot to the group and use the API method. Group CHAT_ID usually starts with - (e.g., -100123456789).

🧰 Prerequisites

  • bash – To run the script
  • curl – For Telegram API communication
  • jq – For JSON processing
  • docker – For container management
  • (Optional) tmux / screen – For long-running execution

Note: All tools must be installed on the host machine.

⚙️ Configuration

BOT_TOKEN The Telegram bot token obtained from @BotFather.
CHAT_ID The numeric ID of the chat or group where the bot responds.
DOCKER Docker executable path (default: /usr/bin/docker).
TEST_MODE If true, the bot won't send any messages (for testing).

🔐 Security: Store your token and CHAT_ID in environment variables or a separate file.

▶️ How to Run

1

Download the telegram-container-monitoring.sh file.

2

Set the BOT_TOKEN and CHAT_ID variables inside it.

3

Make the file executable: chmod +x telegram-container-monitoring.sh

4

Run the script: ./telegram-container-monitoring.sh

5

Open your bot in Telegram and send /list.

💡

For stable background execution, use tmux or screen.

🖥️ Run as a Systemd Service (Ubuntu)

To run the script permanently in the background, you can use a systemd service. This ensures the script starts automatically on server boot and restarts if it crashes.

1

Create a new service file in /etc/systemd/system/:
sudo nano /etc/systemd/system/hadi-monitor.service

2

Add the following content (replace the script path with the actual one): 

[Unit]
Description=HADI Telegram Monitoring Service
After=docker.service network.target
Requires=docker.service

[Service]
Type=simple
User=root
ExecStart=/bin/bash /path/to/telegram-container-monitoring.sh
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target

⚠️ Note: Replace /path/to/telegram-container-monitoring.sh with the actual path to your script.

3

Save the file and exit the editor (Ctrl+X, then Y, then Enter).

4

Reload systemd to recognize the new service: sudo systemctl daemon-reload

5

Enable the service to start automatically on boot: sudo systemctl enable hadi-monitor.service

6

Start the service: sudo systemctl start hadi-monitor.service

7

Check the service status: sudo systemctl status hadi-monitor.service

📊

View service logs with sudo journalctl -u hadi-monitor.service -f. To stop the service: sudo systemctl stop hadi-monitor.service

📝 Set Bot Commands After Getting Token

After obtaining your bot token, you need to set up its commands so users can see available features. Use BotFather for this.

1

Message @BotFather on Telegram.

2

Send /mybots and select your bot.

3

Choose Edit Bot → Edit Commands.

4

Enter your command list in this format (one per line):
command1 - Description of command 1
command2 - Description of command 2

5

For the /list command, use this description:

list - Show main menu for container management (logs / restart)
6

After sending, the new commands will be active immediately in your bot.

💡

Custom commands appear when users type / in the chat with your bot, making interaction much easier.

👥 Add Bot to Group and Grant Admin Access

To use the bot in groups, first add it to the group and then grant admin permissions so it can manage messages.

1

Find your bot on Telegram and click on its name.

2

Select Add to Group.

3

Choose your group and add the bot.

4

In the group, click on the bot's name and select Manage Group.

5

In Administrators, click Add Admin.

6

Select your bot from the list and enable the necessary permissions (e.g., send messages, delete messages, manage members).

7

Confirm to add the bot as a group admin.

💡

Granting admin access allows the bot to manage messages and respond to user requests properly. Without this, the bot cannot function correctly in groups.

📟 The /list Command

The /list command is the main entry point for interacting with the bot. When you send it, the bot responds with an inline keyboard showing two options:

  • 📋 Logs – Select this to view and download logs from any container.
  • 🔄 Restart – Select this to restart any container.

After selecting either option, the bot shows a list of all available containers (including stopped ones) for you to choose from.

💡

The /list command can also be used to redisplay the main menu if you need to go back.

📟 Bot Commands

CommandDescription
/listShow main menu (logs / restart)
(Button clicks)Select container and perform action

After selecting a container, logs are sent as a .log file.
