Mansoori Telegram Überwachung

Verwalten und überwachen Sie Docker-Container über einen Telegram-Bot

🚀 Docker 🤖 Telegram Bot 📊 Echtzeit

🔍 Überblick

Dieses Tool ermöglicht es Ihnen, Ihre Docker-Container über einen Telegram-Bot remote zu verwalten. Logs anzeigen, Container neu starten und Berichte erhalten – alles mit wenigen Klicks in Telegram.

✨ Funktionen

📋

Logs abrufen

Wählen Sie einen Container und erhalten Sie seine neuesten Logs als Datei.

🔄

Neustart

Starten Sie jeden Container mit einem einfachen Befehl neu.

📱

Telegram Zugriff

Erledigen Sie alles von Ihrem Telefon aus – ohne SSH oder Terminal.

⚡

Schnelle Reaktion

Der Bot hört kontinuierlich auf Ihre Anfragen.

🤖 Erstellen Sie einen Telegram-Bot

1

Öffnen Sie Telegram und schreiben Sie @BotFather.

2

Senden Sie den Befehl /newbot.

3

Wählen Sie einen Namen für Ihren Bot (z.B. Mansoori Monitor).

4

Wählen Sie einen Benutzernamen, der mit bot endet (z.B. mansoori_monitor_bot).

5

Kopieren Sie nach der Bestätigung den Token (z.B. 123456:ABC-DEF...). Dies ist Ihr BOT_TOKEN.

💡

Bewahren Sie Ihren Bot-Token sicher auf. Geben Sie ihn niemals weiter.

🆔 CHAT_ID abrufen

1

Starten Sie Ihren Bot in Telegram (Start drücken oder /start senden).

2

Um Ihre numerische Chat-ID zu erhalten, verwenden Sie eine dieser Methoden:

3

Methode 1: Verwenden Sie den Bot @userinfobot. Starten Sie ihn und senden Sie /start. Er zeigt Ihre ID an.

4

Methode 2 (API): Nachdem Sie Ihrem Bot eine Nachricht gesendet haben, öffnen Sie diese URL in Ihrem Browser:
https://api.telegram.org/bot<TOKEN>/getUpdates
(Ersetzen Sie <TOKEN> durch Ihren Bot-Token.)

5

Suchen Sie in der JSON-Ausgabe nach "chat":{"id":123456789}. Die Zahl in id ist Ihre CHAT_ID.

⚠️

Wenn Sie eine Gruppe verwenden, fügen Sie den Bot zur Gruppe hinzu und verwenden Sie die API-Methode. Die Gruppen-CHAT_ID beginnt normalerweise mit - (z.B. -100123456789).

🧰 Voraussetzungen

  • bash – Zum Ausführen des Skripts
  • curl – Für die Telegram-API-Kommunikation
  • jq – Für die JSON-Verarbeitung
  • docker – Für die Container-Verwaltung
  • (Optional) tmux / screen – Für die langfristige Ausführung

Hinweis: Alle Tools müssen auf dem Host-Rechner installiert sein.

⚙️ Konfiguration

BOT_TOKEN Der Telegram-Bot-Token, der von @BotFather erhalten wurde.
CHAT_ID Die numerische ID des Chats oder der Gruppe, in der der Bot antwortet.
DOCKER Docker-Ausführungspfad (Standard: /usr/bin/docker).
TEST_MODE Wenn true, sendet der Bot keine Nachrichten (für Tests).

🔐 Sicherheit: Speichern Sie Ihren Token und Ihre CHAT_ID in Umgebungsvariablen oder einer separaten Datei.

▶️ Ausführung

1

Laden Sie die Datei telegram-container-monitoring.sh herunter.

2

Setzen Sie die Variablen BOT_TOKEN und CHAT_ID darin.

3

Machen Sie die Datei ausführbar: chmod +x telegram-container-monitoring.sh

4

Führen Sie das Skript aus: ./telegram-container-monitoring.sh

5

Öffnen Sie Ihren Bot in Telegram und senden Sie /list.

💡

Für die stabile Hintergrundausführung verwenden Sie tmux oder screen.

🖥️ Als Systemd-Dienst ausführen (Ubuntu)

Um das Skript dauerhaft im Hintergrund auszuführen, können Sie einen systemd-Dienst verwenden. Dadurch wird das Skript automatisch beim Serverstart ausgeführt und bei Abstürzen neu gestartet.

1

Erstellen Sie eine neue Dienstdatei in /etc/systemd/system/:
sudo nano /etc/systemd/system/mansoori-monitor.service

2

Fügen Sie den folgenden Inhalt ein (ersetzen Sie den Skriptpfad durch den tatsächlichen): 

[Unit]
Description=Mansoori Telegram Überwachungsdienst
After=docker.service network.target
Requires=docker.service

[Service]
Type=simple
User=root
ExecStart=/bin/bash /path/to/telegram-container-monitoring.sh
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target

⚠️ Hinweis: Ersetzen Sie /path/to/telegram-container-monitoring.sh durch den tatsächlichen Pfad zu Ihrem Skript.

3

Speichern Sie die Datei und verlassen Sie den Editor (Ctrl+X, dann Y, dann Enter).

4

Laden Sie systemd neu, um den neuen Dienst zu erkennen: sudo systemctl daemon-reload

5

Aktivieren Sie den Dienst für den automatischen Start beim Booten: sudo systemctl enable mansoori-monitor.service

6

Starten Sie den Dienst: sudo systemctl start mansoori-monitor.service

7

Überprüfen Sie den Dienststatus: sudo systemctl status mansoori-monitor.service

📊

Dienst-Logs anzeigen mit sudo journalctl -u mansoori-monitor.service -f. Zum Stoppen des Dienstes: sudo systemctl stop mansoori-monitor.service

📝 Bot-Befehle nach Token-Erhalt einrichten

Nachdem Sie Ihren Bot-Token erhalten haben, müssen Sie seine Befehle einrichten, damit Benutzer die verfügbaren Funktionen sehen können. Verwenden Sie dafür BotFather.

1

Schreiben Sie @BotFather auf Telegram.

2

Senden Sie /mybots und wählen Sie Ihren Bot aus.

3

Wählen Sie Edit Bot → Edit Commands.

4

Geben Sie Ihre Befehlsliste in diesem Format ein (einer pro Zeile):
befehl1 - Beschreibung von Befehl 1
befehl2 - Beschreibung von Befehl 2

5

Für den Befehl /list verwenden Sie diese Beschreibung:

list - Hauptmenü für Container-Verwaltung anzeigen (Logs / Neustart)
6

Nach dem Senden sind die neuen Befehle sofort in Ihrem Bot aktiv.

💡

Benutzerdefinierte Befehle erscheinen, wenn Benutzer / im Chat mit Ihrem Bot eingeben, was die Interaktion viel einfacher macht.

👥 Bot zur Gruppe hinzufügen und Admin-Zugriff gewähren

Um den Bot in Gruppen zu verwenden, fügen Sie ihn zunächst zur Gruppe hinzu und gewähren Sie dann Admin-Berechtigungen, damit er Nachrichten verwalten kann.

1

Finden Sie Ihren Bot auf Telegram und klicken Sie auf seinen Namen.

2

Wählen Sie Zu Gruppe hinzufügen.

3

Wählen Sie Ihre Gruppe und fügen Sie den Bot hinzu.

4

Klicken Sie in der Gruppe auf den Namen des Bots und wählen Sie Gruppe verwalten.

5

Klicken Sie unter Administratoren auf Admin hinzufügen.

6

Wählen Sie Ihren Bot aus der Liste und aktivieren Sie die erforderlichen Berechtigungen (z.B. Nachrichten senden, Nachrichten löschen, Mitglieder verwalten).

7

Bestätigen Sie, um den Bot als Gruppen-Admin hinzuzufügen.

💡

Die Gewährung von Admin-Zugriff ermöglicht es dem Bot, Nachrichten zu verwalten und auf Benutzeranfragen richtig zu reagieren. Ohne diese Berechtigung kann der Bot in Gruppen nicht richtig funktionieren.

🛠️ Benutzerdefinierte Befehle für Ihren Telegram-Bot erstellen

Um Ihrem Telegram-Bot neue Befehle hinzuzufügen, verwenden Sie BotFather. Benutzerdefinierte Befehle helfen Benutzern, die Funktionen Ihres Bots zu entdecken.

1

Schreiben Sie @BotFather auf Telegram.

2

Senden Sie /mybots und wählen Sie Ihren Bot aus.

3

Wählen Sie Edit Bot → Edit Commands.

4

Geben Sie Ihre Befehlsliste in diesem Format ein (einer pro Zeile):
befehl1 - Beschreibung von Befehl 1
befehl2 - Beschreibung von Befehl 2

5

Für den Befehl /list verwenden Sie diese Beschreibung:

list - Hauptmenü für Container-Verwaltung anzeigen (Logs / Neustart)
6

Nach dem Senden sind die neuen Befehle sofort in Ihrem Bot aktiv.

💡

Benutzerdefinierte Befehle erscheinen, wenn Benutzer / im Chat mit Ihrem Bot eingeben, was die Interaktion viel einfacher macht.

📟 Der /list-Befehl

Der Befehl /list ist der Haupt-Einstiegspunkt für die Interaktion mit dem Bot. Wenn Sie ihn senden, antwortet der Bot mit einer Inline-Tastatur, die zwei Optionen anzeigt:

  • 📋 Logs – Wählen Sie diese Option, um Logs von jedem Container anzuzeigen und herunterzuladen.
  • 🔄 Neustart – Wählen Sie diese Option, um einen beliebigen Container neu zu starten.

Nach der Auswahl einer Option zeigt der Bot eine Liste aller verfügbaren Container (einschließlich gestoppter) zur Auswahl an.

💡

Der Befehl /list kann auch verwendet werden, um das Hauptmenü erneut anzuzeigen, wenn Sie zurückkehren müssen.

📟 Bot-Befehle

BefehlBeschreibung
/listHauptmenü anzeigen (Logs / Neustart)
(Button-Klicks)Container auswählen und Aktion ausführen

Nach der Auswahl eines Containers werden die Logs als .log-Datei gesendet.
